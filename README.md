# PPS / PPS+ — Personal Privacy Signal for Physical AI

**Experimental interoperability proposal · Candidate engineering specification v0.1**

PPS / PPS+ explores machine-readable privacy preferences for nearby Physical-AI systems such as smart glasses, cameras, wearables and robots.

## Status
This repository is the public external-review baseline for PPS/PPS+ v0.1. It is **not a W3C standard**, is not endorsed by W3C, and does not claim adoption or enforcement by commercial smart-glasses manufacturers. Reliable camera-to-person subject binding remains an explicit research problem.

## Core safety principle
A received radio signal is not proof of a person's visual identity. PPS separates discovery, authenticity/freshness, subject binding, policy resolution and actual enforcement.

## Review baseline
The repository contains the frozen v0.1 protocol, policy mapping, security requirements, threat model, manufacturer integration profile, conformance specification and vectors, reference receiver, and independent validation protocol.

Independent implementation and security review are invited through GitHub Issues.
