# Specification workspace

The candidate baseline remains in [wire protocol](../spec/PPS-WIRE-PROTOCOL-v0.1.md),
[policy](../spec/PPS-POLICY-MAPPING-v0.1.md), [security](../security/PPS-SECURITY-REQUIREMENTS-v0.1.md)
and [conformance](../conformance/PPS-CONFORMANCE-v0.1.md). Do not create a second
normative copy. This workspace adds proposals and navigation.

Discuss an issue, use [proposal template](PROPOSAL-TEMPLATE.md), then submit a
focused PR under [governance](../GOVERNANCE.md). Label Informative / Proposed /
Candidate / Superseded and record editor, revision, baseline and unresolved dissent.
No file here is a recognized international standard. Use the
[conformance checklist](CONFORMANCE-CHECKLIST.md) and keep protocol, research
package, implementation commit and release versions distinct.
