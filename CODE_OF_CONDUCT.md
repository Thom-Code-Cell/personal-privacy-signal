# Community conduct

Treat people with respect regardless of background, identity, affiliation or
technical experience. Critique claims and evidence; welcome newcomers, dissent,
independent forks and negative results. Provide accessible explanations.
Harassment, discrimination, threats, doxxing, sexual harassment, publication of
private data and retaliatory behaviour are unacceptable.

Applies to project issues, PRs, Discussions and project-associated activities.
Moderators may edit/remove harmful material, warn, temporarily restrict or ban
participation according to severity. Record a minimal reason without exposing a
reporter; immediate restrictions may be needed for threats or personal data.

Report ordinary conduct problems with GitHub's Report content flow to avoid
posting private details publicly. Repository owner Thom-Code-Cell handles project
moderation; GitHub abuse reporting is the independent escalation if the owner is
involved. Do not open public issues naming a victim or containing private evidence.
Appeal via a safe GitHub moderation/reporting channel; a non-involved maintainer
should review if available. Currently there is no independent project appeal panel.
Reports are handled with minimum disclosure; absolute confidentiality or response
times cannot be guaranteed. Security reports follow SECURITY.md.

This is an original project policy, not an assertion of adoption by another body.
