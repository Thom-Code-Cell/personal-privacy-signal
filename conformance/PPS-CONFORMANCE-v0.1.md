# PPS Conformance v0.1

Status: Candidate test specification
Date: 2026-10-06

Reports MUST separately state wire-parser conformance, policy-semantic conformance, T0/T1/T2 support, binding conformance, enforcement-domain support and safety-exception conformance.

Minimum families: C-PRIV identifiers/rotation/correlation; C-PARSE valid/length/version/type/reserved; C-POLICY flags/combinations/zero-is-not-consent; C-REPLAY; C-AUTH; C-BIND; C-DOS; C-ENFORCE; C-SAFETY; C-VERSION.

A normative requirement passes only with observable evidence. Untested = NOT TESTED. Unsupported = UNSUPPORTED. Advisory-only = ADVISORY.

Every report records implementation/version, protocol version, policy version, date, hardware/OS, trust levels, enforcement domains, vector revision and deviations.

Candidate conformance is not certification. Production/certified wording requires stable normative specifications, governance, independent implementation evidence and security review.
