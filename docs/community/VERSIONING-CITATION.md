# Versioning and citation

Protocol candidate **v0.1**, research package **v1.0** and repository commits are
separate identifiers. No formal software release or DOI is claimed.

Use full commit hashes for reproducible research. Editorial changes preserve
wire semantics; compatible clarifications need change notes and vectors; changes
to wire layout, trust assumptions or policy meanings require an explicitly reviewed
new protocol version. Mark experimental APIs unstable; never silently redefine a
frozen version. Any future release needs owner approval, provenance/license review,
final-commit checks and a changelog distinguishing measured/unmeasured behaviour.

Suggested citation (replace brackets with the revision actually used):

> TH Analytica / Thomas Hullin and PPS contributors. PPS / PPS+ — Personal Privacy
> Signal, candidate protocol v0.1, research package v1.0. GitHub repository,
> commit [full SHA], accessed [YYYY-MM-DD].
> https://github.com/Thom-Code-Cell/personal-privacy-signal

Cite independent implementations and reports separately with their authors,
revision and evidence class. Attribution preserves origin without implying
endorsement, ownership of others' results, W3C affiliation or patent permission.
A future archive/DOI deposit is a separate publication decision, not automatic.
